# Simple Linear Regression: Salary Prediction
This project implements a **Simple Linear Regression** model to predict salary based on years of experience. It focuses on the relationship between independent and dependent variables, utilizing data visualization techniques to demonstrate the model's accuracy and the trend of the data.
## 🛠 Tech Stack
The following Python libraries were used to build and visualize this model:
 * **Scikit-Learn (sklearn):** Used for building, training, and testing the Linear Regression model.
 * **Matplotlib:** Used for fundamental data visualization and plotting.
 * **Seaborn:** Used for advanced statistical graphics and improving the aesthetics of the plots.
 * **Pandas & NumPy:** Used for data manipulation, cleaning, and preprocessing.
## 📊 Project Highlights
The project includes comprehensive visual analysis to ensure the model's logic is clear:
 * **Scatter Plot:** Visualizes the raw data points to observe the initial distribution and correlation between experience and salary.
 * **Line Plot:** Represents the "Best Fit Line" generated by the regression model, showing the predicted trend.
 * **Regression Analysis:** Utilized seaborn.regplot to overlay the regression line on the scatter data, providing a clear visual representation of the model's fit and confidence intervals.
